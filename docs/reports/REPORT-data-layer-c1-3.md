## ข้อสังเกต

- `npm run build` สร้าง `asset-manifest.json` ก่อน build → `dist` ต่างจาก `7555525` เพียงไฟล์นี้ไฟล์เดียว (ไม่กระทบภาพหรือการทำงาน)
- `validateConfig` ของรุ่นปัจจุบัน (v5) ยังไม่ได้เพิ่มการตรวจ BD-001 — ตั้งใจไว้ เพื่อไม่ให้การตั้งค่าที่บันทึกไว้ในเครื่องผู้ใช้เปิดไม่ได้ก่อนย้ายข้อมูล · การตรวจอยู่ในขั้นตรวจก่อนย้ายและเอกสาร v6
- รหัสชั้นในหน้าจอ (`G`, `5`, `11`) ยังเป็นรหัสเดิม — ชั้นใน v6 มี UUID + `code` แปลงที่ขอบเมื่อเชื่อมหน้าจอ
- ฐาน @v6 ยังไม่มีโค้ดแอปใดเปิดใช้ — การย้ายข้อมูลจะเกิดจริงเมื่อเชื่อมในขั้นถัดไปหลังได้รับอนุมัติ
